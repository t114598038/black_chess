# PBI-004 Web Frontend MVP

## Status
Done

## Description
Create a functional web-based user interface:
- **Game Board**: Responsive 4x8 grid rendering pieces (covered/revealed).
- **Room Join UI**: Form to enter room IDs and select game modes (AI/PvP).
- **Game Controls**: Buttons for starting the game, terminating matches, and viewing status.
- **Visual Feedback**: Animations or highlights for selected pieces and last moves.
