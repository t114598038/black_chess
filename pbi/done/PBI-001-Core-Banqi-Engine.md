# PBI-001 Core Banqi Engine

## Status
Done

## Description
Implement the core logic for Chinese Dark Chess (Banqi), including:
- Board initialization with 32 pieces.
- Movement rules for all piece types (King, Guard, Elephant, Car, Horse, Cannon, Soldier).
- Special rules: Soldier can eat King; Cannon moves 1 step but jumps to eat.
- Game over conditions: Checkmate, piece exhaustion, or 50-move draw.
- Turn management and valid move validation.
